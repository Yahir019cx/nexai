# NEXAI
# 013 - Roadmap Frontend

> **Versión:** 1.0
> **Estado:** Activo
> **Prioridad:** Obligatorio

---

# Objetivo

Definir el orden en el que deberá desarrollarse el frontend de NEXAI.

El objetivo es construir primero las bases del proyecto y posteriormente las funcionalidades.

Nunca comenzar desarrollando pantallas sin antes tener una base sólida.

---

# Filosofía

Cada etapa debe dejar una aplicación completamente funcional.

No crear código pensando únicamente en el futuro.

Cada fase debe representar un avance real del producto.

---

# Fase 1
## Fundación

Objetivo

Construir la base del proyecto.

Incluye:

- Configuración inicial.
- Router.
- Temas.
- Componentes base.
- Layout principal.
- Navegación.
- Responsive.
- Sidebar.
- Sistema de animaciones.

Resultado esperado

Una aplicación funcional sin lógica de negocio pero con identidad visual completa.

---

# Fase 2

- NexChip
- NexTooltip

---

# Regla General

Nunca comenzar una fase si la anterior no está estable.

Cada fase deberá finalizar con una aplicación completamente funcional.

---

# Calidad

Antes de cerrar una fase deberán revisarse:

- Diseño.
- Responsive.
- Animaciones.
- Rendimiento.
- Consistencia visual.
- Componentes reutilizables.
- Código limpio.

---

# Principio Final

No construir funcionalidades por velocidad.

Construir una plataforma sólida que pueda crecer durante los próximos años sin perder calidad.
