# NEXAI
# 023 - Atajos de Teclado y Experiencia Desktop

> **Versión:** 1.0
> **Estado:** Activo
> **Prioridad:** Alta

---

# Objetivo

Definir la experiencia de uso para escritorio.

NEXAI está diseñado principalmente para Desktop.

El usuario deberá poder utilizar la aplicación durante horas sin depender constantemente del mouse.

El teclado será un ciudadano de primera clase.

---

# Filosofía

Toda acción frecuente deberá poder realizarse mediante un atajo.

El objetivo es aumentar la productividad.

No agregar atajos innecesarios.

Solo aquellos que realmente aporten valor.

---

# Command Palette

NEXAI contará con una Command Palette similar a:

- VS Code
- Raycast
- Linear
- Warp

Permitirá ejecutar acciones sin navegar por la interfaz.

---

## Atajo

```
Ctrl + K
```

o

```
Ctrl + Shift + P
```

---

# Nuevo Chat

```
Ctrl + N
```

Crear una nueva conversación.

---

# Enviar Prompt

```
Ctrl + Enter
```

Enviar el mensaje.

---

# Nueva Línea

```
Shift + Enter
```

Insertar un salto de línea.

---

# Buscar Conversaciones

```
Ctrl + F
```

Buscar dentro del historial.

---

# Configuración

```
Ctrl + ,
```

Abrir configuración.

---

# Cambiar Tema

```
Ctrl + Shift + T
```

Alternar entre modo claro y oscuro.

---

# Limpiar Conversación

```
Ctrl + Shift + L
```

Limpiar el chat actual.

---

# Cerrar Ventanas

```
Esc
```

Cerrar:

- Diálogos.
- Menús.
- Dropdowns.
- Tooltips abiertos.
- Paneles temporales.

---

# Navegación

Las flechas del teclado deberán permitir navegar por:

- Conversaciones.
- Menús.
- Dropdowns.
- Resultados de búsqueda.

---

# Tabulación

La tecla TAB deberá recorrer los elementos de forma lógica.

Nunca deberá perderse el foco.

---

# Focus

Todo componente interactivo deberá tener un estado Focus claramente visible.

Sin romper la identidad visual.

---

# Selección

Las listas deberán poder utilizarse completamente mediante teclado.

Ejemplo:

↑

↓

Enter

Esc

---

# Menús Contextuales

Cuando sea posible deberán abrirse mediante teclado.

No depender únicamente del clic derecho.

---

# Copiar Código

Los bloques de código deberán permitir copiar utilizando:

```
Ctrl + C
```

cuando el bloque tenga el foco.

---

# Accesibilidad

Toda funcionalidad importante deberá poder utilizarse sin mouse.

---

# Desktop First

La experiencia Desktop no será una adaptación de Mobile.

Será la experiencia principal del producto.

Las demás plataformas se adaptarán a ella.

---

# Cursores

Todo elemento interactivo deberá mostrar el cursor correcto.

Ejemplos:

- Pointer.
- Text.
- Resize.
- Grab.
- Grabbing.

Nunca utilizar un único cursor para todo.

---

# Drag & Drop

El sistema deberá prepararse para soportar:

- Archivos.
- Imágenes.
- Carpetas.
- Texto.

La interacción deberá sentirse natural.

---

# Selección de Texto

El usuario deberá poder seleccionar y copiar texto libremente.

Nunca bloquear la selección sin una razón válida.

---

# Scroll

Desktop deberá soportar correctamente:

- Mouse.
- Trackpad.
- Rueda.
- Scroll horizontal cuando aplique.

El desplazamiento deberá sentirse fluido.

---

# Futuro

La experiencia Desktop podrá ampliarse con:

- Múltiples ventanas.
- Pestañas.
- Paneles acoplables.
- Atajos personalizables.
- Command Palette avanzada.
- Quick Actions.

La arquitectura deberá permitir incorporar estas funciones sin grandes cambios.

---

# Regla Final

La experiencia Desktop debe sentirse como una aplicación profesional.

El usuario debe poder trabajar durante horas utilizando principalmente el teclado, con una interfaz rápida, fluida y cómoda.
