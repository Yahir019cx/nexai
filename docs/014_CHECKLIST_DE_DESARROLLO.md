# Experiencia

Antes de dar una tarea por terminada responder:

¿La usaría diariamente?

¿Parece un producto comercial?

¿Se siente mejor que una aplicación Flutter promedio?

¿Estoy orgulloso de esta implementación?

Si alguna respuesta es NO,

la tarea aún no está terminada.

---

# Definición de "Terminado"

Una funcionalidad únicamente podrá considerarse terminada cuando:

- Funcione correctamente.
- Sea visualmente consistente.
- Sea responsive.
- Respete la documentación.
- Pase este checklist completo.

Si no cumple alguno de estos puntos, deberá seguir iterándose hasta alcanzar el estándar de calidad de NEXAI.
