# NEXAI
# 024 - Microinteracciones

> **Versión:** 1.0
> **Estado:** Activo
> **Prioridad:** Alta

---

# Objetivo

Las microinteracciones son pequeños detalles que hacen que la aplicación se sienta viva.

No son animaciones decorativas.

Son respuestas visuales que indican al usuario que la interfaz entiende lo que está haciendo.

Una buena microinteracción casi pasa desapercibida.

Su ausencia sí se nota.

---

# Filosofía

Cada interacción debe generar una reacción.

Nunca dejar al usuario preguntándose si ocurrió algo.

Las respuestas deben ser:

- Rápidas.
- Naturales.
- Elegantes.
- Sutiles.

Nunca exageradas.

---

# Mouse Hover

Todo elemento interactivo deberá reaccionar al pasar el cursor.

Ejemplos:

- Cambio de opacidad.
- Cambio ligero de color.
- Elevación muy sutil.
- Glow mínimo.
- Cambio de cursor.

Nunca utilizar movimientos exagerados.

---

# Click

Al hacer clic:

- Escala ligera.
- Feedback inmediato.
- Transición suave.

El usuario debe sentir que el componente respondió.

---

# Focus

Cuando un componente obtenga el foco deberá indicarlo claramente.

Ejemplos:

- Borde.
- Glow.
- Cambio de color.

Nunca romper la estética del proyecto.

---

# Botones

Hover

- Cambio suave de color.

Pressed

- Escala mínima.
- Menor brillo.

Loading

- Cambio automático al estado de carga.

Disabled

- Menor opacidad.
- Sin interacción.

---

# Sidebar

Hover

- Resaltar opción.

Seleccionado

- Indicador visual.
- Transición animada.

Expandir

- Movimiento suave.

Colapsar

- Movimiento suave.

Nunca instantáneo.

---

# Chat

Cuando llegue un mensaje nuevo:

- Fade.
- Slide ligero.
- Aparición progresiva.

Nunca aparecer de golpe.

---

# Streaming

Cada palabra deberá aparecer naturalmente.

No simular escritura extremadamente lenta.

No mostrar bloques completos instantáneamente.

Debe sentirse inteligente.

---

# Prompt

Cuando el usuario escriba:

- Activar estado.
- Mostrar botón de envío.
- Ajustar altura automáticamente.

Cuando quede vacío:

- Regresar suavemente al estado inicial.

---

# Inputs

Focus

- Glow suave.
- Cambio de borde.

Error

- Cambio de color.
- Mensaje elegante.

Success

- Feedback discreto.

---

# Dropdowns

Abrir

- Fade.
- Scale.

Cerrar

- Fade.

Nunca aparecer instantáneamente.

---

# Dialogs

Abrir

- Fade.
- Scale.
- Blur del fondo.

Cerrar

- Animación inversa.

---

# Tooltips

Mostrar únicamente después de un pequeño retraso.

Ocultarse inmediatamente al salir.

Nunca permanecer demasiado tiempo.

---

# Toasts

Entrar

- Slide.
- Fade.

Salir

- Fade.

Nunca bloquear la interfaz.

---

# Cards

Hover

- Elevación ligera.
- Glow muy suave.

Nunca más de unos pocos píxeles.

---

# Scroll

El scroll debe sentirse suave.

Nunca brusco.

Nunca entrecortado.

---

# Drag & Drop

Cuando un elemento pueda recibir archivos:

Mostrar claramente que acepta la acción.

Sin exagerar.

---

# Thinking

El indicador de procesamiento debe sentirse exclusivo de NEXAI.

No utilizar:

- Spinner clásico.
- Barras infinitas.
- GIFs.

Buscar una identidad propia.

---

# Partículas

Si existen partículas en el fondo:

Podrán reaccionar ligeramente al movimiento del cursor.

Nunca deberán distraer.

---

# Cursor

Todo elemento interactivo deberá utilizar el cursor adecuado.

No utilizar siempre el mismo cursor.

---

# Duración

Las microinteracciones deben sentirse rápidas.

Nunca hacer esperar al usuario.

---

# Consistencia

Todas las microinteracciones deberán seguir el mismo lenguaje visual.

No mezclar estilos.

No improvisar animaciones.

---

# Regla Final

Las microinteracciones son la diferencia entre una aplicación que funciona y una aplicación que transmite calidad.

Cada interacción debe sentirse cuidadosamente diseñada.

El usuario puede no recordarlas.

Pero sí recordará cómo se sintió utilizar NEXAI.
