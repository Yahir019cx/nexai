# Introducción

Este documento define la visión general de NEXAI.

No describe código.

No describe arquitectura.

No describe tecnologías.

Este documento describe **qué es NEXAI**, cómo debe sentirse, cuál es su identidad y qué principios deben seguirse durante todo el desarrollo.

Toda decisión de diseño, experiencia de usuario o implementación deberá respetar este documento.

---

# ¿Qué es NEXAI?

NEXAI no es un simple chat con inteligencia artificial.

NEXAI es una plataforma diseñada para convertirse en el espacio de trabajo principal donde las personas interactúan con distintos modelos de IA de forma natural.

El chat es únicamente una de las funcionalidades.

A futuro la plataforma incluirá:

- Chat con IA.
- Agentes inteligentes.
- Modelos locales (Ollama).
- Modelos en la nube.
- Generación de imágenes.
- Análisis de documentos.
- Automatizaciones.
- Bases de conocimiento.
- MCP Servers.
- Espacios de trabajo colaborativos.

Cada nuevo módulo deberá sentirse como parte del mismo ecosistema.

---

# Filosofía del producto

NEXAI debe transmitir:

- Elegancia.
- Simplicidad.
- Tecnología.
- Fluidez.
- Inteligencia.
- Profesionalismo.

El usuario nunca debe sentirse perdido.

Cada interacción debe sentirse natural.

Cada animación debe tener un propósito.

Nada debe existir únicamente por decoración.

---

# Lo que NEXAI NO debe ser

NEXAI NO debe parecer:

❌ Un clon de ChatGPT.

❌ Un clon de Claude.

❌ Una aplicación Flutter genérica.

❌ Una interfaz llena de botones.

❌ Un dashboard empresarial aburrido.

❌ Un proyecto hecho con widgets por defecto.

Nuestra identidad debe ser única.

---

# Identidad visual

La interfaz debe sentirse:

Minimalista.

Premium.

Moderna.

Futurista.

Elegante.

Con mucho espacio visual.

Nunca saturada.

---

# Colores oficiales

Color principal

#00B8C0

Variaciones

#009CA5

#02ACB2

#00C0C7

Fondo principal

#000000

La paleta debe utilizarse con moderación.

El color principal debe utilizarse para dirigir la atención del usuario, no para pintar toda la interfaz.

---

# Fondo

El fondo de NEXAI nunca debe sentirse completamente estático.

Puede utilizar:

- partículas
- puntos
- conexiones
- gradientes
- desenfoques
- iluminación suave

Todo debe ser extremadamente sutil.

El fondo debe acompañar la experiencia, nunca distraer.

---

# Movimiento

Las animaciones forman parte de la identidad de NEXAI.

Toda aparición de elementos debe tener una transición suave.

Se priorizan:

- Fade
- Scale
- Slide
- Blur
- Spring
- Morph

Las animaciones deben sentirse naturales.

Nunca exageradas.

---

# Experiencia de usuario

La interfaz debe transmitir calma.

Debe existir abundante espacio entre componentes.

El contenido importante debe respirar.

Menos elementos generan una mejor experiencia.

La tipografía tiene más importancia que el uso excesivo del color.

---

# Filosofía de desarrollo

Flutter únicamente es el motor.

La identidad pertenece a NEXAI.

Nunca debemos diseñar pensando en Material Design.

Debemos diseñar pensando en la experiencia del usuario.

---

# Principio final

Antes de implementar cualquier funcionalidad debemos hacernos una pregunta:

> ¿Esto hace que NEXAI se sienta más premium?

Si la respuesta es NO,

la implementación debe replantearse.
