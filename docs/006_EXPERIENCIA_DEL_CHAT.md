# NEXAI
# 006 - Experiencia del Chat

> **Versión:** 1.0
> **Estado:** Activo
> **Prioridad:** Obligatorio

---

# Objetivo

Definir cómo debe sentirse la experiencia principal de NEXAI.

El chat es el corazón del producto.

No estamos construyendo una pantalla para enviar mensajes.

Estamos construyendo una experiencia de conversación con inteligencia artificial.

Todo debe sentirse natural.

---

# Filosofía

El usuario debe sentir que conversa con una inteligencia viva.

No con una aplicación.

La experiencia debe ser:

- Fluida.
- Elegante.
- Rápida.
- Clara.
- Relajada.

Nunca pesada.

Nunca saturada.

---

# Layout General

La interfaz se divide en tres zonas principales.

```
┌────────────────────────────────────────────────────────────┐
│ Sidebar │                  Chat                  │ Opcional│
│         │                                        │ Panel   │
│         │                                        │ Lateral │
└────────────────────────────────────────────────────────────┘
```

La prioridad visual siempre será el área del chat.

---

# Sidebar

La Sidebar deberá contener únicamente:

- Nuevo chat.
- Historial de conversaciones.
- Búsqueda.
- Configuración.
- Perfil.
- Cerrar sesión.

No debe contener información innecesaria.

---

# Historial

Las conversaciones deberán agruparse automáticamente.

Ejemplo:

Hoy

Ayer

Esta semana

Este mes

Más antiguas

Esto facilita la navegación cuando existan muchas conversaciones.

---

# Conversaciones

Cada conversación deberá mostrar:

- Nombre.
- Fecha.
- Última actividad.

Opcionalmente:

- Modelo utilizado.
- Icono.
- Favorito.

---

# Área Principal

Debe existir mucho espacio visual.

Nunca llenar toda la pantalla.

El texto debe respirar.

---

# Estado Vacío

Cuando no exista conversación activa se mostrará una pantalla atractiva.

Debe incluir:

- Logo.
- Bienvenida.
- Acciones rápidas.
- Prompts sugeridos.

Nunca mostrar una pantalla vacía.

---

# Prompt

El Prompt es uno de los elementos más importantes.

Debe sentirse como una herramienta profesional.

No como un TextField tradicional.

Debe incluir soporte para:

- Texto.
- Adjuntos.
- Cambio de modelo.
- Herramientas futuras.
- Botón enviar.

Todo integrado.

---

# Input

El área de escritura debe crecer automáticamente.

Nunca debe romper el diseño.

Debe mantener siempre una altura cómoda.

---

# Mensajes

Los mensajes deben ser fáciles de leer.

Mucho espacio.

Excelente jerarquía.

Buena separación.

Nada comprimido.

---

# Markdown

Las respuestas de la IA deberán soportar correctamente:

- Encabezados.
- Tablas.
- Código.
- Listas.
- Enlaces.
- Imágenes.
- Citas.
- Bloques destacados.

Todo deberá mantener la identidad visual de NEXAI.

---

# Código

Los bloques de código deben sentirse premium.

Deben incluir:

- Resaltado de sintaxis.
- Botón copiar.
- Scroll horizontal.
- Bordes suaves.

Nunca utilizar estilos genéricos.

---

# Thinking

Cuando la IA esté procesando información:

No mostrar únicamente un texto.

El usuario debe percibir actividad.

El indicador debe sentirse moderno.

No infantil.

---

# Streaming

Las respuestas deberán generarse progresivamente.

Nunca aparecer completas de golpe.

El usuario debe sentir que la IA está escribiendo.

La transición debe ser completamente fluida.

---

# Acciones del Mensaje

Cada respuesta podrá incluir acciones.

Ejemplo:

- Copiar.
- Regenerar.
- Editar Prompt.
- Compartir.
- Continuar respuesta.

Estas acciones deberán aparecer únicamente cuando sean necesarias.

---

# Edición

El usuario podrá editar mensajes enviados.

La conversación deberá continuar desde ese punto.

---

# Scroll

El desplazamiento debe sentirse natural.

Nunca brusco.

Al llegar una nueva respuesta el comportamiento debe ser inteligente.

No mover la pantalla innecesariamente.

---

# Adjuntos

El sistema deberá prepararse para soportar:

- PDF.
- Word.
- Excel.
- Imágenes.
- Texto.
- Código.
- Audio.
- Video.

Aunque inicialmente no todos estén implementados.

---

# Cambio de Modelo

El modelo utilizado deberá poder cambiarse fácilmente.

La interfaz deberá mostrar claramente cuál modelo está respondiendo.

---

# Estados

La conversación deberá contemplar:

- Vacía.
- Cargando.
- Pensando.
- Respondiendo.
- Error.
- Sin conexión.

Cada estado deberá tener una experiencia propia.

---

# Errores

Los errores nunca deberán mostrarse como ventanas molestas.

Deberán sentirse integrados con la interfaz.

Explicar claramente el problema.

Ofrecer una solución.

---

# Responsive

En Desktop

La Sidebar permanece visible.

En Tablet

La Sidebar puede colapsarse.

En Mobile

La Sidebar se convierte en panel deslizable.

El chat siempre tendrá prioridad.

---

# Experiencia

El usuario nunca debe pensar:

"Estoy usando un chat."

Debe pensar:

"Estoy trabajando con una plataforma de inteligencia artificial."

---

# Principio Final

El chat no es una lista de mensajes.

Es el espacio donde ocurre toda la experiencia de NEXAI.

Cada detalle debe transmitir calidad, precisión y confianza.
